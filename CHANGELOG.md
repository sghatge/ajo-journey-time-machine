# Changelog

All notable changes to this project are documented here.

## [0.1.0] — 2026-11-26

### Added
- Synthetic event fixture and deterministic shadow simulator.
- Fail-closed consent and opt-out eligibility checks.
- Four scenario choices in the Streamlit control room.
- Profile-level journey traces and simplified journey-flow visualization.
- Baseline-versus-scenario comparison.
- Explainable heuristic risk intelligence.
- SHA-256 hash-chain audit evidence and JSON export.
- Read-only MCP tool for local synthetic simulation.
- GitHub Actions quality gate using pytest and Python compilation.
- Mobile-responsive UI refinements.
- Architecture and portfolio case-study documentation.

### Safety
- Explicitly documented that the project is not an Adobe AEP/AJO emulator or Adobe-certified product.
- No production customer data, campaign sending, publishing, pausing or activation functionality.
- Simulation results remain advisory and require human review.
